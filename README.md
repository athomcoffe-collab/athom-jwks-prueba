# athom-jwks-prueba

Repositorio de **PRUEBA** de Athom Control.

Su único propósito es publicar, mediante GitHub Pages, las claves **públicas** de firma (JWKS) del entorno de prueba.

- Contendrá solo `jwks.json`, con claves públicas ES256 (`kid`, `kty`, `crv`, `x`, `y`, `alg`, `use`).
  Por ahora **no contiene ninguna clave**.
- Nunca contendrá claves privadas, secretos, código, flujos de trabajo ni datos.
- No es el entorno real de Athom Control y se borrará al terminar las pruebas.
